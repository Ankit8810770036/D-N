## How to Run the Project
1. **Backend (Laravel 12 API)**:
   ```powershell
   cd backend
   php artisan serve
   ```
   *(Server runs at http://127.0.0.1:8000)*

2. **Frontend (React 18 + Vite 6)**:
   ```powershell
   cd frontend
   npm run dev
   ```
   *(App runs at http://localhost:5173)*
